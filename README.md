# swe-physrag

Small starter library for physics-informed RAG experiments based on the SWE equation.

## Current status

This repository is in an early setup phase. The goal is to build a clean, extensible Python package that combines:

- SWE-based physical modeling
- Retrieval-Augmented Generation (RAG) data access
- Modular, maintainable architecture for future growth

## Project structure

- `physrag/` — package source code
- `data/` — local datasets and experiment artifacts

## Notes

This README is intentionally minimal and will be expanded as features and workflows are added.
